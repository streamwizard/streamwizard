## The fast way: Alert box template

**New Overlay → Alert box**. That's it. The overlay comes with an alert
widget already placed, listening for follows, subs, cheers, and raids.

Click the widget to customize it in the right panel:

- **Alert image**: pick from your [media library](/overlays/media-library).
- **Alert sound**: same, with a volume slider.
- **Accent color** and **seconds on screen**.
- **Per-event toggles**: only want follows and raids? Switch the rest off.

Alerts queue. If three people follow at once, you get three alerts back to
back, not one mangled one.

## Adding alerts to an existing overlay

In the editor: **Widgets → Library → Starters → Alert box → Add to canvas**.

## Testing

Open the widget's code editor (**Edit code** in its settings) and use the test
buttons above the preview: Follow, Sub, Cheer, Raid. Hit **Connect** to test
against real events from your channel.

## Making it fancier

The alert box is a regular custom widget you own. **Edit code** opens the
full editor where you can change the animation, layout, or add more events.
See [building widgets](/widgets/overview) if you want to go down that road.
